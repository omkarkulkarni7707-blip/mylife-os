# MyLife OS — Premium PWA v2

Premium personal dashboard for morning ritual, budget, petrol, trading, gratitude, tasks and risk management.

## Features
- Morning ritual + monthly consistency calendar
- Daily tasks with priorities
- Monthly budget + expenses
- Petrol cost + km/L analytics
- Trading journal + automatic P&L
- Risk calculator: capital + risk % + entry + stop-loss → quantity
- Trading win rate and average trade analytics
- Gratitude journal
- Local browser storage and JSON backup
- Offline PWA support

## Privacy
This prototype stores data locally in the browser on the device. No cloud database is configured yet.


Deployment configured for GitHub Pages.
