# Debt-Free Personal Planner

A mobile-first personal debt tracker hosted separately from the main MyLife OS dashboard.

## Features
- Track multiple loans, current principal, APR, EMI, minimum payment and due dates
- Record principal and interest/fee portions of each payment
- View overall progress and per-loan payoff progress
- Compare avalanche (highest APR first), snowball (smallest balance first) and hybrid payoff order
- Export loans and payments to CSV; back up and restore all data as JSON
- Installable PWA with basic offline caching

## Open on Android
After GitHub Pages is enabled for this repository, open:
`https://omkarkulkarni7707-blip.github.io/mylife-os/debt/`
In Chrome, use the three-dot menu and choose **Add to Home screen** or **Install app** if offered.

## Privacy
Loan details are stored in the browser's local storage on the device. They are not sent to a server. Export a backup regularly. Clearing browser site data can erase planner records. This is a planning tool, not financial advice.

## GitHub Pages
The root site and this subdirectory can be served from the repository's Pages deployment. Enable Pages in repository Settings → Pages if it is not already enabled.
